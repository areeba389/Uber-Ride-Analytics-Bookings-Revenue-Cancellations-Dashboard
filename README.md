🚗 Uber Ride Analytics Dashboard
About the Project

This project is about understanding how Uber rides work using real ride-sharing data.
I created a dashboard to study bookings, completed rides, cancellations, revenue, and customer behavior in a simple and visual way.

The goal was to turn raw data into clear insights that anyone can understand.

Dataset Used

Uber Ride Analytics Dataset (Kaggle)

Contains 148,000+ ride records

Includes details like:

Ride status (completed or cancelled)

Vehicle type

Trip distance and time

Payment method

Customer and driver ratings

Tools Used

Microsoft Excel – for cleaning and organizing the data

Power BI – for creating the dashboard and visuals

What This Dashboard Shows

Total number of bookings

Completed rides vs cancelled rides

Revenue split by payment method

Performance of different vehicle types

Average ride distance and duration

Customer and driver ratings

Key Learnings

Most users prefer digital payments like UPI

Customer cancellations are more common than driver cancellations

Auto and bike rides have a high success rate

Ratings help understand service quality and user experience

Purpose of This Project

This project was created to practice data analysis and dashboard building skills and to understand how data can help improve business decisions.
